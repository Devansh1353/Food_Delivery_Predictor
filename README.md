# Food Delivery Time Prediction Using Linear and Logistic Regression

This project focuses on applying two fundamental machine learning algorithms, Linear Regression and Logistic Regression, to a food delivery dataset. The objective is to demonstrate how different machine learning models can be used to solve different types of prediction problems using the same dataset.

The dataset contains information related to food delivery operations, including delivery distance, traffic conditions, weather conditions, delivery partner ratings, and vehicle type. These features are used to analyze delivery performance and make predictions based on real-world delivery scenarios.

In the Linear Regression implementation, the model is trained to predict the exact delivery time of an order in minutes. This is a regression problem because the target variable is continuous in nature. By analyzing factors such as distance, traffic level, weather conditions, and delivery ratings, the model estimates how long a delivery is likely to take.

In the Logistic Regression implementation, the model is trained to predict whether an order will be delivered on time or delayed. This is a classification problem where the target variable is categorical. The output is represented as either 1 (On Time) or 0 (Delayed). The performance of the model is evaluated using metrics such as Accuracy Score and Classification Report.

The project was developed using Python and several popular data science libraries, including Pandas for data manipulation, NumPy for numerical operations, Scikit-Learn for machine learning model development, and Matplotlib for data visualization. The implementation was carried out in Visual Studio Code using a dedicated Python virtual environment.

This project serves as a practical demonstration of supervised machine learning techniques and highlights the differences between regression and classification approaches. It also provides hands-on experience with data preprocessing, model training, testing, evaluation, and result interpretation.

The repository contains the dataset, source code for both Linear Regression and Logistic Regression models, and all files required to reproduce the results.
